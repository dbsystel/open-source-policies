# Contribution Policy

This directory contains the public version of the open source contribution policy which is used by DB Systel.

The document is provided as AsciiDoc template. Certain terms and sections are filled in through AsciiDoc includes. These includes are not provided as part of the template. They are supposed to be filled in by documents specific to the organization using the policy. Terms are defined in the variables file included in the first line of the template.

There are two versions of the policy, one [in German](contribution-richtlinie.adoc) and an [English translation](contribution-guideline.en.adoc).
